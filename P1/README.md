# Práctica 1 - Visión por Computador

Primera práctica de la asignatura de **Visión por Computador**, realizada utilizando Python y OpenCV.

## Contenido

En esta práctica se realizan varios ejercicios básicos de tratamiento de imágenes:

* Creación de un tablero de ajedrez de 8x8.
* Creación de una imagen inspirada en el estilo de Mondrian.
* Detección del píxel más claro y más oscuro de una imagen capturada por la cámara.
* Creación de un efecto Pop Art en tiempo real utilizando diferentes gamas de colores.


## Ejecución

Para ejecutar la práctica es necesario tener instaladas las librerías utilizadas:

```bash
pip install opencv-python numpy matplotlib
```

Después se puede abrir el archivo:

```text
VC_P1_Entrega_Grupo33.ipynb
```

desde Jupyter Notebook o Visual Studio Code y ejecutar las celdas en orden.

Para los ejercicios que utilizan vídeo es necesario disponer de una cámara conectada al equipo.
